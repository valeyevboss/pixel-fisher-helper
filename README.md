## ℹ️ Описание
**Pixel Fisher Helper** - современный рыболовный хелпер для SA-MP / Arizona RP, превращающий обычную ловлю рыбы в полноценную аналитическую систему. Скрипт в реальном времени отслеживает вашу добычу, рассчитывает чистый доход и ведет подробный учёт предметов.

---

## ✨ Ключевые возможности
* **Детальная статистика:** точный подсчёт словленной рыбы, рыбных монет, ценных предметов и заработка с продаж с сохранением истории сессий.
* **Полная кастомизация:** гибкая настройка внешнего вида и параметров хелпера под ваш вкус.
* **Интерактивные уведомления:** информативные оверлей уведомления и чат-сообщения о каждом ключевом действии (поимка рыбы, выпадение предмета, продажа улова)..
* **Оверлей:** удобный виджет на вашем экране с выводом текущих показателей в реальном времени. Можно перемещать в любое место экрана через настройки, изменять размер и включать/выключать фон (для лучшей читабельности информации).
* **Современный UI:** стильный, гибкий и адаптивный интерфейс на mimgui.

## ⚙️ Установка
1. Установите **MoonLoader** и библиотеку **mimgui**.
2. Поместите файл `Pixel Fisher Helper.lua` в папку `moonloader`.
3. Папку `pixel_fisherhelper` поместите в папку `moonloader/config`.

## 🎮 Активация
* **Клавиша:** `F2`
* **Команда в чате:** `/fmenu`
* **Помощь по всем командам:** `/fhelp`
